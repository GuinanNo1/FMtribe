**The LFO, and the panel in pages.** The LFO moves the pitch, the filter or both, at FAST (about 1 Hz to 5 kHz) or
SLOW (0.05 to 18 Hz) rates, or plays half a cycle as each note starts (1 SHOT), with saw, triangle, square or
sample-and-hold waves. FAST and 1 SHOT restart with each note.

The panel now works in pages: a button shows its page, pressed again its next, and K1–K4 edit what's on the
screen; the top right shows which page, such as 1/2.

| Page (button) | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| VCO VCF (SEL) | CUTOFF | PEAK | WAVE | NOISE |
| EG VCA (ENV) | EG | LEVEL | RHYTHM | |
| LFO 1/2 (LFO) | RATE | INT | TARGET | MODE |
| LFO 2/2 (LFO) | WAVE | | | |
| GLOBAL (GLO) | SYNTH CH | DRUM CH | BLE MIDI | |

The MIDI channels are settable, and the monotribe's LFO controllers work (CC 1, 16, 81–83). The drum pads move
to ARP, EDIT and FX until the sequencer, which comes next on SEQ. Settings saved by earlier versions don't carry over.
