**MIDI settings together on GLOBAL 1/3.** SYNC and CLOCK OUT move from SEQ STEPS to GLOBAL 1/3 (GLO), beside
the MIDI channels, so all the MIDI settings are on one page. BLE MIDI (Bluetooth on or off) moves to GLOBAL 2/3. SEQ STEPS keeps STEPS on K1 and PART on K4.

| Page (button) | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| SEQ STEPS 2/3 (SEQ) | STEPS | | | PART |
| GLOBAL 1/3 (GLO) | SYNTH CH | DRUM CH | SYNC | CLOCK OUT |
| GLOBAL 2/3 (GLO) | KEY LIGHT | GLOW | BLE MIDI | |
